# 登录页面 Demo

基于原生 HTML、CSS 和 JavaScript 的静态登录演示，使用 Node.js 内置 HTTP 服务，无需安装第三方依赖。

## 设计文档

[爱莉希雅主题登录页设计共识](doc/爱莉希雅主题登录页设计共识.md)：记录已确认的双主题形态对应、颜色职责、动态表现方向及仍需验证的参数。

## 启动

需要 Node.js 22 或更高版本。在项目目录执行：

```bash
npm start
```

访问 <http://127.0.0.1:11451>，按 `Ctrl+C` 停止服务。服务仅监听本机回环地址 `127.0.0.1`，端口固定为 `11451`。修改页面文件后刷新浏览器即可查看效果。

修改 `server.js`（包括新增图片路由）后需要重新启动服务。若 Windows 与 WSL 各自运行了服务，应重启浏览器实际访问的那个进程；旧进程可能能读到新页面，但对新增图片仍返回 404。

## 演示页面

- `/`：刻印与晶棱输入框组成的登录页，输入演示密钥 `123` 后按 Enter，框内展开“欢迎回来”，文字与输入框一并收起，刻印归中、完全点亮并淡出后进入业务首页。空值及其他密钥会触发输入框整体左右抖动，同时累积刻印裂损；左下角五格次数条每错一次点亮一格，并随输入框展开、收起。前四次以三条主裂痕逐步延长、张开和加深为主，保持主体连接，仅少量局部碎片弹出；仍可输入，正确登录时光流同步闭合裂痕、复原碎片。第五次收紧到极限，停留约 85ms，再小幅快速迸裂；晶片具有前后深度、三轴倾转、厚度侧面及方向光，散开后保留并独立轻微漂浮。破碎完成后，输入框以“欢迎回来”相同动效展开“错误次数过多，请稍后刷新重试”，停止接受输入，可刷新或点击左上角“重置”重新开始。前四次不显示错误文字，长按 Enter 不重复计数。
- `/dashboard.html`：静态业务工作台。

当前仅在前端比较演示密钥，没有真实身份校验或访问控制，不保存或发送输入内容，业务数据均为演示数据。

左上角“开始动画”可预览当前裂损状态的点亮修复，完成后不跳转；第五次错误锁定后仅可重置。刷新和重置会清空本轮错误次数及裂损。
