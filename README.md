# 登录页面 Demo

基于原生 HTML、CSS 和 JavaScript 的静态登录演示，使用 Node.js 内置 HTTP 服务，无需安装第三方依赖。

## 设计文档

[爱莉希雅主题登录页设计共识](doc/爱莉希雅主题登录页设计共识.md)：记录已确认的双主题形态对应、颜色职责、动态表现方向及仍需验证的参数。

## 启动

需要 Node.js 22 或更高版本。在项目目录执行：

```bash
npm start
```

访问 <http://127.0.0.1:11451>，按 `Ctrl+C` 停止服务。服务仅监听本机回环地址 `127.0.0.1`，端口固定为 `11451`。修改页面文件后刷新浏览器即可查看效果。

## 演示页面

- `/`：终端风格登录页，输入任意非空 token 后按 Enter 进入业务首页。
- `/dashboard.html`：静态业务工作台。

当前没有真实身份校验或访问控制，不保存或发送 token，业务数据均为演示数据。
