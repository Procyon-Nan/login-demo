# 登录页面 Demo

基于原生 HTML、CSS 和 JavaScript 的静态登录演示，使用 Node.js 内置 HTTP 服务，无需安装第三方依赖。

## 设计文档

[爱莉希雅主题登录页设计共识](doc/爱莉希雅主题登录页设计共识.md)：记录已确认的双主题形态对应、颜色职责、动态表现方向及仍需验证的参数。

## 启动

需要 Node.js 22 或更高版本。在项目目录执行：

```bash
npm start
```

访问 <http://127.0.0.1:11451>，按 `Ctrl+C` 停止服务。服务仅监听本机回环地址 `127.0.0.1`，端口固定为 `11451`。修改页面文件后刷新浏览器即可查看效果。

修改 `server.js`（包括新增图片路由）后需要重新启动服务。若 Windows 与 WSL 各自运行了服务，应重启浏览器实际访问的那个进程；旧进程可能能读到新页面，但对新增图片仍返回 404。

## 演示页面

- `/`：刻印与晶棱输入框组成的登录页，输入演示密钥 `123` 后按 Enter，框内展开“欢迎回来”，文字与输入框一并收起，刻印归中、完全点亮并淡出后进入业务首页。空值及其他密钥会触发输入框整体左右抖动，保留输入内容与焦点，不显示错误文字；刻印破碎反馈及五次错误上限尚未实现。
- `/dashboard.html`：静态业务工作台。

当前仅在前端比较演示密钥，没有真实身份校验或访问控制，不保存或发送输入内容，业务数据均为演示数据。
