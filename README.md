# Elysia API 登录页

基于原生 HTML、CSS 和 JavaScript 的独立登录页。保留刻印点亮、裂损修复、双主题背景和移动端布局，通过认证适配文件接入宿主项目。无需安装第三方依赖。

## 启动

需要 Node.js 22 或更高版本。在项目目录执行：

```bash
npm start
```

访问 <http://127.0.0.1:11451>，按 `Ctrl+C` 停止服务。服务仅监听本机回环地址 `127.0.0.1`，端口固定为 `11451`。修改页面文件后刷新浏览器即可查看效果。

修改 `server.js`（包括新增图片路由）后需要重新启动服务。若 Windows 与 WSL 各自运行了服务，应重启浏览器实际访问的那个进程；旧进程可能能读到新页面，但对新增图片仍返回 404。

## 当前行为与接入

- `/` 和 `/index.html` 提供同一登录页；调试按钮、固定演示密码、临时业务页及其样式已移除。
- 在 `login-adapter.js` 实现 `authenticate(token, { signal })` 和可选的 `onAuthenticated(result)`。当前认证未配置，非空提交提示“登录服务尚未接入”，不放行、不发起认证请求。
- 认证通过后展开“欢迎回来”，收起输入框、刻印归中并点亮，同时修复此前裂损。配置了完成回调时，完整点亮停留 360ms、淡出 360ms 后由宿主导航；未配置回调则停留在完整点亮状态。
- 空值或适配器明确拒绝的密钥累积五格次数与刻印裂损。第五次完全破碎后保留碎片，显示“错误次数过多，请稍后刷新重试”并锁定输入；刷新页面重新开始。网络或服务异常不增加错误次数。

本仓库不提供认证后端、会话存储或业务页面；`server.js` 仅用于本地预览静态资源。真实身份校验、会话及服务端限流由宿主项目负责。

主题首次加载及未手动选择时持续跟随浏览器的 `prefers-color-scheme`。点击右上角按钮后，本次页面内使用手动选择；刷新后重新跟随浏览器，不保存主题偏好。

亮色主题采用“晨雾花庭”：暖白与浅粉紫薄雾中，花瓣从上方缓缓飘落，轻微横摆、翻转；暗色主题保留向上游动的弧形尾迹萤火。背景在刻印与输入框就位后开始运动，花瓣与萤火共用主体及底部字标的柔边遮挡。右上角切换主题不重置登录状态；后台暂停，减少动态效果时保持静态。花瓣与萤火参数位于 `background-particles.js` 顶部，晨雾的色彩和周期位于 `backgrounds.css`。
