# 爱莉希雅主题登录页设计共识

更新日期：2026-09-21  
状态：主题方向、核心色板与颜色职责已确认；具体视觉参数待页面试制验证。

本文记录本项目讨论后确认的设计依据。此前素材目录中的讨论纪要和研究笔记作为参考；涉及本轮已确认事项时，以本文为准。文档中的待定事项不应被视为已确认的实施参数。

## 1. 页面目标与交互约束

- 制作以爱莉希雅为主题的网页登录页，重点呈现「真我·人之律者」相关形象与动态交互。
- 登录只需要一个 access token 输入框，不需要账号输入，也不增加冗长说明。
- 页面布局简洁，以终端式输入、干净细线为基础，不使用厚重卡片包裹输入区。
- 输入框由一个中心点分别向左上和右下展开形成；明暗主题保持同一套展开轨迹。
- 输入区不使用闭合矩形包围。当前试制为两枚细小晶瓣从同一中心沿对角线分离，再分别带出渐淡弧线，保留左上、右下开放轮廓；具体曲率与时序待视觉反馈调整。
- 现有业务首页作为登录后的展示示例，并保留“重新登录”控件，方便重放登录流程。
- 当前 demo 仅演示跳转，未实现真实 token 校验、身份认证或访问控制；视觉设计共识不改变这一实现状态。

## 2. 已确认的双主题与形态对应

| 主题 | 对应形态 | 色彩方向 | 视觉气质 |
| --- | --- | --- | --- |
| 明亮主题 | 人之律者 | 粉白、浅粉、薰衣草紫，少量冰蓝 | 柔和、轻盈、无瑕、透光 |
| 暗色主题 | 始源之律者 | 深紫、夜空蓝紫、晶体紫、星海蓝与粉色高光 | 深邃、梦幻、星海、发光 |

两套主题及对应关系已经确定，不再将“是否实现双主题”列为待决策事项。该对应是本网站对角色视觉的设计转译，不代表官方形态只能使用对应明度的配色。

两套主题共享标志性粉色 `#E58ABD`，通过背景、光感与材质表达形态差异。暗色主题以深紫与夜空蓝紫构成空间，不以纯黑为视觉核心。

| 金色细节 | `#C7A376` | 少量装饰 |

### 使用规则

- 粉色承担角色识别，不承担所有文字、边框和交互状态。
- 明亮主题需要看清的输入框细线、提交符号等优先使用真我紫，输入文字使用深紫墨。
- 暗色主题可直接用粉色表达输入框强调与聚焦状态，文字采用柔和粉白。
- 浅粉色填充上的普通文字采用深色，不直接套用粉白文字。
- 冰蓝用于折射和晶体尖端，不成为持续发亮的整圈输入框边框。
- 金色用于小节点或短线，不贯穿整个输入框，不作为大面积背景。
- 单输入框页面无需同时突出全部粉色色阶；画面层级应保持克制。

## 4. 背景与光感

### 明亮主题

粉白占据大部分视野，粉紫在局部柔和显现，冰蓝集中于少量高光边缘。

原纪要中的四段线性渐变可供试制参考，但渐变角度、色标及铺陈面积没有定稿。避免让粉、紫、蓝形成同等显眼的全屏色带，导致画面失去角色辨识度。

### 暗色主题

保留深紫基底，以局部夜空蓝紫及远近不同的细小亮点建立空间。角色关联的粉色仍是主要识别焦点。

冰蓝亮度较高，需要限制范围和持续时间。背景纹理与粒子应避开或弱化输入区，保证细线和文字清晰。

## 5. 双主题的材质与动态表现方向

| 位置 | 明亮主题：人之律者 | 暗色主题：始源之律者 |
| --- | --- | --- |
| 中心起点 | 有清晰轮廓的小晶核 | 微微发光的小晶核 |
| 展开线条 | 紫色细线，局部粉色反光 | 粉紫细线，有限的发光 |
| 输入文字 | 深紫墨 | 柔和粉白 |
| 冰蓝表现 | 接近透明的边缘折射 | 少量、短暂的亮点 |
| 整体材质 | 透光、轻薄 | 发光、深远 |

以上作为已接受的试制方向，形状细节、动画时长、光晕范围与粒子数量仍需结合真实页面确定。现有展开轨迹是共同交互骨架，主题变化主要通过材质和光感表达。

## 6. 已完成的纯色对比度核算

2026-09-21 按 WCAG 相对亮度公式计算。结果为不透明纯色组合，保留两位小数，仅用于评估颜色职责，不代表实际页面已通过完整可访问性检查。

| 前景 / 背景 | 对比度 | 用途判断 |
| --- | --- | --- |
| `#E58ABD` / `#FCF9FD` | 2.31:1 | 不适合普通小字或唯一的关键控件轮廓 |
| `#7550A8` / `#FCF9FD` | 5.80:1 | 可用于普通文字及重要交互 |
| `#3A2946` / `#FCF9FD` | 12.68:1 | 正文与输入内容清晰 |
| `#E58ABD` / `#171222` | 7.59:1 | 可承担暗色交互强调 |
| `#FCF9FD` / `#E58ABD` | 2.31:1 | 不适合普通按钮文字 |
| `#3A2946` / `#E58ABD` | 5.49:1 | 可用于粉色填充上的普通文字 |
| `#8FD9ED` / `#171222` | 11.62:1 | 亮度突出，需避免抢占主要视觉焦点 |

普通文字通常以 4.5:1 为最低要求；识别控件及状态所必需的非文字视觉信息通常要求与相邻颜色达到 3:1。纯装饰线条无需全部达到此标准。最终仍需检查实际背景、透明度、渐变和光效叠加后的结果。

## 7. 已确认的背景主题

- 2026-09-22：原花海、星海试制效果过于粗糙，已移除花朵、飘瓣、星点、动态星云及对应动画和控制逻辑。
- 明亮主题采用“晨雾花庭”：以 `#FCF9FD` 为中央留白，暖白基底上叠加玫瑰粉、柔紫、珍珠白薄雾，分别以 23–35 秒周期轻柔舒展。暗色主题保持 `#171222` 与原有静态渐变。
- 暗色背景参考用户提供插画中的萤火与细长弧形尾迹，仅提取光点及轨迹，不加入人物、树林、月亮或花丛；亮色模式停用萤火，改为自上而下的花瓣。
- 刻印移动、输入框展开全部完成后才启动花瓣、萤火与晨雾运动。暗色萤火仅在页面下方三分之二区域随机出生并错开淡入；顶部三分之一区域允许已有光点游入，不生成新光点。重新进入登录流程时清空并等待主体再次就位。
- 光点整体持续向上，带平滑的随机横向偏移，每次重生重新生成方向、弧度和寿命；保留用户当前设置的桌面最多 30 条、窄屏 25 条、基础寿命 30–60 秒，上升速度为每秒视口高度的 2.3%–3.4%，并根据出生高度缩短寿命至抵达上边缘前；尾段淡出时长随寿命调整，尾迹保留最近 5–8 秒的路径并连续收细、消隐，不闪烁。头部柔光略增强，通过尺寸与亮度差异表现远近。
- 亮色花瓣桌面最多 18 片、窄屏 12 片；以每秒视口高度的 1.8%–2.8% 向下飘落，从视口上方或顶部附近错开淡入，在下边缘淡出。使用两种不对称薄瓣轮廓、浅折痕和柔和渐变填色，配合横摆、缓慢旋转和 7–13 秒的翻面变化；不使用光点、尾迹或额外泛光。大小与透明度体现远近，保持疏朗。
- 数量、速度、出生高度、花瓣尺寸、遮挡留白和柔边宽度集中在 [background-particles.js](../background-particles.js) 顶部，均附中文注释；该模块由原萤火模块扩展并更名，复用绘制循环、生命周期与遮罩。晨雾颜色及周期位于 [backgrounds.css](../backgrounds.css)。
- 刻印、输入框和底部 Elysia API 字标（含两侧横线）使用跟随实际布局的柔边遮罩，进入时平滑遮挡花瓣或萤火，区域外的部分继续显示；被遮挡期间仍按原轨迹和寿命运行，存活的粒子离开遮挡区后平滑显现。主体显隐时遮挡强度也平滑过渡。点亮刻印时减弱背景，减少动态效果模式保持静态且随主体布局更新遮挡区域。
- 明亮花瓣使用玫瑰粉 `#D68BB0` 与浅紫 `#B88FBE` 的透明渐变，暗色萤火沿用爱莉粉 `#E58ABD` 与晶体紫 `#B8A2E8`；不沿用参考图中的青色。
- 已选定晨雾花庭，移除四方案预览控件及其他三版图层。主题切换时重新生成对应花瓣或萤火并淡入，不重置登录状态。晨雾在暗色模式下隐藏并暂停；所有背景运动在后台暂停，减少动态效果模式使用静态画面。具体密度、速度和色彩强度仍可根据视觉反馈调整。

## 8. 已确认的底部字标

- 页面底部居中展示名称 `Elysia API`，采用带幻想感的艺术手写字形。
- 文字左右各有一条横线，保持细线、轻盈的视觉。
- 动画顺序：文字由左到右依次书写显现，全部完成后，左右横线从靠近文字的位置分别向外延伸。
- 已选定手写字体预选中的 H03 Italianno Regular（设计者 Robert Leuschke），替换试用的 Mazius Display。候选与来源见[手写字体预选名单](../素材/Elysia-API_手写字体预选/预选名单与来源.md)。
- 当前动画通过 Italianno 的 SVG 字形轮廓与逐字描边遮罩呈现，不是实际手写笔顺采样；保留装饰笔画所需留白，文字颜色继续跟随明暗主题。
- 文字在页面载入后延迟 100ms 开始，书写持续 1400ms，在 1.5 秒内全部显示；随后两侧横线展开，持续 950ms。
- 进入登录页时播放一次，主题切换时不重播；减少动态效果模式直接展示完成状态。

## 9. 尚未定稿的事项

### 刻印主体试制（2026-09-21）

- 已确定登录页中心主体由刻印与输入框组成；刻印完全亮起后才进入业务页面。
- 点亮过程不显示“刻印正在点亮”“刻印已点亮”等说明文字，仅以视觉变化表达。
- 未点亮刻印的边缘线条在亮色模式使用暗紫色 `#65408B`，深色模式使用粉色 `#E58ABD`，增强与背景的区分；保留细轮廓及现有透明度，点亮过程与终态仍沿用原有颜色。
- 未点亮时以 5.5 秒周期上下轻浮，总位移 7px；主体轮廓保持固定颜色和透明度，由同一轮廓生成的独立柔光层与浮动共用 5.5 秒周期和缓动，浮起时逐渐变亮、最高点最亮，落下时逐渐变暗、最低点最暗，表现线条自发光。提交瞬间从当前位置、亮度转为向峰值上升，下降段镜像到同状态的上升段；上升与收起输入框、刻印归中同时进行，达峰后保持。归中及达峰完成后直接从当前状态点亮，保持峰值位置，不重置或整体淡出；轮廓柔光由笔画充盈逐点替换为原生泛光，完成后保持静止。后台暂停，减少动态效果时关闭；暂不加入局部微光。
- 入场时刻印先居中显现（500ms），等待底部字体及两侧横线全部显示完毕后，平滑左移（720ms）到位后，右侧输入框再从中心向左上、右下展开（900ms）。正确密钥提交后先隐藏输入内容（100ms），在框内居中展开“欢迎回来”（约 500ms），完整停留约 600ms，再让文字与两处晶棱一并向中心收起（360ms）。刻印在欢迎阶段保持左侧位置，随后回到视口中央（720ms），等待从提交瞬间开始的单向上升达到峰值后直接点亮（2000ms）。各段等待实际动画结束；减少动态效果时将欢迎文字静态展示 650ms，跳过位移及上升等待。调试预览包含欢迎阶段，完整点亮后留在中央，不跳转；已点亮状态重播直接预览刻印点亮。
- 当前布局试制：桌面刻印在左、开放式输入框在右，两者垂直对齐并作为整体在视口居中；刻印最大 400px，输入框最大 360px，最大间距 100px，组合总宽自动相加，最大为 860px。在 `login.css` 的 `.login-scene` 中通过 `--signet-width` 和 `--input-width` 分别调节尺寸，均附中文注释。视口宽度不超过 768px 时改为刻印在上、输入框在下，组合区域水平及垂直居中；组合区域最大宽度 400px，输入框独立限制为最大 300px，可在媒体查询中修改 `--input-width`，不影响刻印。刻印宽度取组合宽度的 80%、300px 和 42svh 中的最小值，间距随视口高度在 24–48px 之间调整，输入框高 72px。移动端刻印先居中显现，字标完成后上移，再展开下方输入框；收起后向下归中点亮，沿用现有时序及缓动。不添加连接竖线。输入框移除右端提交箭头，使用键盘 Enter 登录，移动端键盘使用前往操作。
- 输入框外观采用 [方案对比页](../素材/输入框设计方案对比.html) 中的 C「晶棱」：左上与右下使用斜切折线、短内棱和低透明度切面，长边逐渐消隐并保持开口，呼应刻印几何线条；移除原花瓣弧线及 `>_` 终端符号。明亮主题主线使用紫色，暗色使用粉色；沿用现有展开、收起方向、时长和缓动，仅按新切面中心校准位移起点。
- 移除输入元素的原生 `required`，消除浏览器“请填写此字段”提示，保留 `aria-required` 语义和提交时的空值检查；空白密钥不会进入点亮流程。
- 输入框展开完成后不自动聚焦，默认提示“请输入登陆密钥”按 110ms 间隔从左到右逐字显示；用户点击或用 Tab 聚焦时立即停止提示动画并隐藏提示，空值失焦后显示完整提示，重置后重新播放。减少动态效果时直接显示完整文字。
- 保留原生密码输入、文本选择和横向滚动；以同样的遮蔽圆点测量插入位置，使用主题紫色／粉色的细光标及局部柔光，光标移动以 110ms 平滑过渡。聚焦后以 1.2 秒周期柔和闪动，输入、删除或移动插入点时立即恢复高亮，再继续等待闪动；选择文本时隐藏光标，失焦或提交时停止闪动并淡出，减少动态效果时保持常亮并取消位置过渡。
- 未点亮轮廓从点亮动画自身的实心覆盖率向内取 2px 边缘生成，共用坐标和抗锯齿，不再加载独立透明线稿。最终点亮形状使用 `素材/刻印.png` 的浅粉白实心图案，运行时副本位于 `assets/images/elysia-signet-solid.png`，原始 PNG 不修改；Canvas 完整保留原图逐像素颜色及自带泛光；半透明洋红区域是泛光，不作为底色删除。完整点亮时不叠加待机柔光，保留素材原生完整泛光强度；泛光由周围笔画亮度经过空间扩散连续驱动，避免外围同步突亮。
- 点亮采用“光子血液”的方向：按笔画内部的传播阻力求出连续到达时间场，光从花心沿内部区域分流，带有柔和亮度前锋，经过处逐渐充盈并稳定为浅粉白。移除短线段拼接与最终实心层淡入，起始和终态由同一渲染器连续计算。点亮进度采用立即推进、末段减速的曲线，减少峰值到充盈之间的视觉停顿；2000ms 点亮完成后保留 360ms 完整状态，再用 360ms 淡出并跳转。
- 算法与可调参数记录于 [刻印点亮算法](刻印点亮算法.md)。此版仍为视觉试制，最终效果以页面反馈为准。
- 当前演示密钥精确设为 `123`，空值或其他输入均以输入框整体左右抖动反馈：边线、输入内容与光标同步移动，最大位移 8px，420ms 内逐步减弱并回到原位。前四次保留输入内容、焦点与选区，不显示错误文字、不标记无效状态、不自动选中文本；重复错误提交重播同一抖动，不叠加。正确提交、调试开始或重置时取消抖动，减少动态效果模式关闭抖动。验证通过后锁定输入及调试开始按钮，避免重复触发流程。仅在前端比较，不代表真实身份认证。跳转等待欢迎文字、收起及刻印点亮依次完成；整页重置和后退恢复清除欢迎状态。
- 输入框左下角新增五格短次数条：初始为空，每次错误立即点亮一格，采用主题紫色／粉色及轻微柔光。次数条以输入框中心为起点，随边框一起展开、收起，锁定后保持五格全亮；刷新、重置及后退恢复清零。窄屏缩短格宽及间距，无额外次数文字。
- 错误反馈试制：前四次错误提交（包含空值）同时触发输入框抖动与刻印累积裂损。主体保持连接，以三条主裂痕逐步延长、扩大开口为主；裂痕沿最终晶片公共边界展开，每轮随机调整方向与偏移，同一轮保持连续。每次约 1200ms，通过暗槽、亮边和局部薄晶面加深断面感；第二至第四次各允许至多一块局部小晶片弹出。第 5 次先用约 306ms 轻微收紧主体、压窄裂口并增强亮边，到达极限后停顿约 85ms，再快速迸开，约 200ms 完成大部分位移，三轴倾转稍慢跟上；整段 1700ms 后进入持续失重漂浮。平面散开幅度由 32–60 收小为 14–26 个画布像素，深度及倾转也收小，保持碎片相互靠近。晶片具有前后深度、透视大小变化、真实笔画厚度侧面及方向高光，朝不同空间方向散开，无统一上浮或下坠。破碎状态保留，不消隐。第 5 次立即停止接受输入、禁用调试开始；待破碎完成，在右侧输入框内展开“错误次数过多，请稍后刷新重试”，复用“欢迎回来”的居中展开与柔光样式，窄屏允许换行。保留现有“重置”按钮，也可刷新重新开始。长按回车不重复计数。
- 破碎后的晶片呈轻薄、透澈的质感：收薄厚度侧面，减弱暗边，以浅透的主题粉紫断面和细亮边表现材质，晶面允许背景明显透过；保留三轴倾转和前后深度带来的空间感。局部弹出的碎片沿用同一材质，避免第五次破碎时材质突变。
- 前四次后正确登录时，欢迎文字、收起与归中沿用已有流程，保留当前裂损；进入点亮后，裂痕随光流到达逐段收窄、闭合，暗槽与亮边退去，同时按各晶片的光流到达时间驱动空间位移、深度和三轴角度复原，厚度侧面及晶面高光同步退去。点亮与修复同时进行，不单独等待修复、不重置成完整线稿。完成帧仍为原图完整颜色及原生泛光。调试开始可预览当前损伤的修复；重置、刷新及后退恢复清空损伤和计数。减少动态效果模式直接显示各次裂损终态或修复终态，并暂停碎片漂浮；后台暂停漂浮，恢复时接续当前位置。
- 上述尺寸、间距、点亮方式及持续时间为本轮试制参数，待页面反馈调整。

### 其他待定事项

- 首次访问默认使用哪一主题，以及主题切换入口的具体形式。
- 人物是否直接出现在登录页，或只通过刻印、晶体和线条表现。
- 后续背景的表现形式、渐变位置及色标比例。
- 边框、占位文字、焦点、悬停、按下和错误状态的完整颜色映射。
- 动画时长、发光强度、透明度、粒子密度与折射细节。
- 实际组件、移动端和减少动态效果模式下的视觉验证。

后续应在单输入框原型中验证上述事项，无需重新讨论已确定的双主题对应关系。
