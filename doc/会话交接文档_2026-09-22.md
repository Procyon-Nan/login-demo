## 1. 接手结论

项目是原生 HTML / CSS / JavaScript 登录页演示，采用爱莉希雅主题，以刻印和单一 access token 输入框为核心。业务示例首页已完成，用户明确要求后续专注登录页，业务页不必修改。

最新一轮联动与待机动画已经得到用户确认并提交。下一会话应以当前效果为基线，等待用户新的具体需求，不需要重新讨论主题、字体、刻印算法，也没有已授权但尚未完成的功能任务。

当前关键效果：

- 初始刻印位于视口中央；底部 `Elysia API` 字体与横线全部显示后，刻印向左平移，右侧输入框随后展开。
- 提交非空 token 时，输入框从左上、右下向中心收起；刻印回到中央，点亮后才进入业务页。
- 桌面刻印约 370px；待机上下总位移 7px，浮动与轮廓自发光共用 6 秒周期，最高点最亮、最低点最暗。
- 输入框展开 900ms，收起 360ms，刻印平移 720ms，点亮 2100ms。
- 左上临时调试按钮保留：“开始动画”预览完整流程但不跳转；“重置”重新加载整页，重播所有入场效果。

## 5. 当前视觉规范

### 5.1 主题与颜色

明亮主题对应人之律者，暗色主题对应始源之律者，这是本网站的设计转译。两套共享粉色 #E58ABD。具体配色职责、纯色对比度历史计算见 [设计共识](爱莉希雅主题登录页设计共识.md)。

| 用途 | 明亮 | 暗色 |
| --- | --- | --- |
| 背景 | #FCF9FD | #171222 |
| 正文 / 输入 | #3A2946 | #F8EEF7 |
| 次要文字 | #755E83 | #B9AFC2 |
| 主要交互 | #7550A8 | #E58ABD |
| 基础输入框线条 | #7550A8 | #A88AE0 |
| 未点亮刻印轮廓 | #65408B | #E58ABD |
| 点亮笔画流动色 | #DA83B8 | #E58ABD |

其他已选色板包括 #F7EAF3、#F1B8D8、#F7A8D8、#B8A2E8、#B9E8F5、#C7A376；暗色局部层次有 #241A32、#8FD9ED。不能因此把全部颜色都做成显眼组件。颜色表属于网站试制规范，不是声称从官方精准采样的标准色。

当前默认跟随系统主题，右上角图标手动切换；手动选择后本页不再跟随系统变更，刷新后重新按系统判定，不持久化。设计共识“其他待定事项”仍保留默认主题等早期候选，接手时要区分最终产品选择与当前代码已具备的行为。

### 5.2 背景

明亮花海以底部稀疏花朵、轻微摇曳、三片不同位置的飘瓣组成；暗色星海有局部星云和固定分布的 36 个低亮星点。移动端减半星点并隐藏部分花朵及飘瓣。分布固定，避免刷新或主题切换随机跳变。

背景留出主体区域，输入非空或登录动画进行时减弱；隐藏标签页暂停背景与待机运动。减少动态效果时静止显示。花朵、星云、星点慢速运动，不加入稠密粒子和持续闪烁。

### 5.3 布局与输入框

- 主体最大宽度 950px，Grid 列比例 370:480，桌面留白最多 100px；窄屏间距 16px，继续左右并列。
- 主体在视口居中；刻印初始及点亮时利用容器相对长度移动至视口中央，输入时回到左列。
- 输入框桌面高 80px，移动端 72px。没有闭合矩形或厚重卡片。
- 两枚晶瓣的位移终点由 `--from-x`、`--from-y` 控制，上侧 47.5% / 37.5%，下侧取反；开放弧线采用描边虚线偏移显现。
- 使用 `access token` 占位、密码输入、细线提交箭头和 Enter。正常过程没有刻印进度说明。
- 实际布局曾检查 1440 / 390 / 320px：刻印宽分别 370 / 约 148.86 / 约 118.39px，无水平溢出。

### 5.4 字标

最终字体为 H03 Italianno Regular。底部 SVG 使用已生成的字形路径与遮罩，不依赖字体网络请求；字体原件与授权仍保留。

延迟 100ms 后开始逐字写出，总书写 1400ms，页面载入后约 1500ms 完成；两侧线随后延伸 950ms，约 2450ms 全部完成。刻印左移等待实际 `Animation.finished`，不写死一个 2450ms 的额外计时器。

遮罩 `stroke-linecap: butt`、`stroke-dasharray: 1 2` 用于避免未写区域先漏色；每字结束时补齐遮罩以填满粗笔画。此实现是艺术字形的渐进揭示，不是精确手写笔顺采样。主题切换不重播字标。

## 6. 动画参数与状态机

| 环节 | 最终参数 |
| --- | --- |
| 刻印居中显现 | 500ms |
| 等待底部字标 | 实际文字与横线动画全部完成 |
| 刻印左移 / 归中 | 720ms，cubic-bezier(.45, 0, .2, 1) |
| 输入框中心点 | 400ms |
| 输入框展开晶瓣 | 延迟 120ms，持续 450ms |
| 输入框展开弧线 | 延迟 260ms，持续 500ms |
| 输入内容显现 | 延迟 660ms，持续 240ms；总入场 900ms |
| 输入内容消失 | 100ms |
| 输入弧线回收 | 230ms |
| 晶瓣向中心收起 | 延迟 50ms，持续 310ms；总收起 360ms |
| 待机浮动 | 0 → -7px → 0，6000ms 无限循环 |
| 待机自发光 | opacity 0 → 1 → 0，6000ms，同帧启动与相同分段缓动 |
| 待机退出 | 从当前位移 / 柔光状态在 600ms 内归零 |
| 刻印点亮 | 2100ms，连续像素充盈 |
| 点亮完整停留 | 360ms |
| 登录主体淡出 | 360ms，之后跳业务页 |

浮动与柔光的 `ease-in-out` 设置在相同的关键帧区间；共享外层 timing 的 easing 为 linear。周期中点 3000ms 位移 -7px、柔光 opacity 1；起点和终点位移 0、柔光 opacity 0。主体线条本身的透明度不随呼吸变化。

`.login-scene` 的 `data-phase` 依次为：

```text
loading → entering（居中显现并等待字标）→ shifting → opening → ready
ready → closing → centering → lighting → lit → 停留与淡出 → dashboard.html
```

`runPhase()` 等元素实际动画完成；`flowId` 标识流程代次，重置后旧异步流程不能继续跳转。点亮渲染器 `play()` 返回是否真正完成；取消返回 false。

调试与恢复：

- “开始动画”无需 token，执行收起、归中、点亮，保持居中完整刻印，不淡出、不跳转。
- 预览完成后输入框隐藏且保持禁用；开始按钮重新可用，再点只重播居中点亮。想重新看入场用“重置”。
- “重置”直接 reload，连同主题初态、字体、横线、输入框和刻印一起恢复。
- `pageshow.persisted` 处理 BFCache 后退恢复，取消旧动画并重新入场；底部字标在 BFCache 恢复时没有被单独强制重播，整页重置才确保全套重播。
- 减少动态效果时关闭待机、缩短 CSS 动画 / 取消 transition，点亮直接绘制终态；保持逻辑顺序。
- 后台暂停背景及待机；点亮 rAF 恢复时限制单帧时间增量 48ms，防止后台时间直接跳完。

## 7. 刻印资产与算法：必须保留的事实

原始输入：`素材/刻印.png`（实心与原生泛光）和 `素材/刻印透明线稿.png`（独立线稿参考）。运行副本分别是 `assets/images/elysia-signet-solid.png` 和 `assets/images/elysia-signet.png`。

当前只加载实心原图生成显示。独立线稿即便对齐外框，局部几何仍不同，直接在未亮时使用会与点亮阶段明显错位；保留文件作参考，不要重新用于画面底图。

**原图的半透明洋红色是素材自带泛光，不是需要去除的底色。** 用户明确要求直接使用素材泛光颜色，并在核对后允许恢复原生强度。当前终态保留完整原始 RGB 和透明度，不额外加全图 CSS 泛光，不在最后一帧换图。

实现摘要（详见 [刻印点亮算法](刻印点亮算法.md) 与 signet.js）：

1. 用 `min(1, green / 240) × sourceAlpha` 提取实心覆盖率，只用于传播几何与轮廓，不能拿它替代最终图片 alpha。
2. 传播场为 192×192；渲染画布为 640×640；采样坐标四周预留 112 单位，ART_SIZE 为 864。CSS 画布向外扩至 135%、inset -17.5%，容纳原生泛光。
3. 从覆盖率向内取半径 2px 圆邻域最小值，用原覆盖率减去侵蚀结果形成轮廓，保留连续抗锯齿。主体未亮轮廓 alpha 系数 0.65。
4. 实心阈值 0.12。双向距离变换估计笔画内部空间，内部传播阻力 `1 + 2 / (distance + 1)`，外部 18。八邻域 Dijkstra 从花心附近传播，归一化到 [0, 0.78]，双线性插值。
5. 每像素局部时间 `age = progress - arrival`。充盈使用 smoothstep(0, .12, age)，颜色稳定用 smoothstep(.025, .21, age)，叠加一次柔和高斯前锋；旧轮廓在同一位置连续消退。
6. 原生泛光独立由已亮实心光源驱动：四方向指数扩散，尺度 7 格，`H = diffuse(E) / diffuse(coreAlpha)`，其中 E 使用 smoothstep(.015, .20, age)。最终 alpha 为 `core × charge + (sourceAlpha - core) × H`。H 完成时自然等于 1，不需要结尾补亮。
7. 独立待机柔光画布也由同一轮廓生成，仅初始化和主题切换时绘制；CSS blur(1.5px) + 同色 drop-shadow(4px)。待机动画操作元素属性，不持续重画像素。
8. 进入登录收起阶段，待机浮动与柔光先平滑退出；完整点亮只剩素材本身泛光。

不能回退的旧做法：短线段拼接、独立线稿与实心图切换、最后整图突然淡入、把洋红 alpha 当背景删除、重建错误颜色的泛光、让所有外围泛光按同一封顶时间同时亮起、通过主体轮廓透明度制造呼吸。
