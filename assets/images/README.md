# 刻印素材

`elysia-signet.png` 原样复制自用户提供的 `素材/刻印透明线稿.png`，保留为设计参考，登录页不加载，本地服务也不再提供这张独立线稿的资源路由。

`elysia-signet-solid.png` 原样复制自用户提供的 `素材/刻印.png`，用于最终浅粉白实心形状及素材自带泛光。完整保留原图的逐像素 RGB 和透明度，洋红色半透明像素属于泛光而非背景。点亮终态的泛光恢复原生完整强度，不叠加待机轮廓柔光；其显现由附近笔画亮度的连续扩散驱动。PNG 文件本身不作修改；画布外扩以容纳整张原图，未点亮轮廓与点亮笔画共用采样坐标。峰值轮廓柔光在点亮时由各处笔画充盈逐点接替，不做整层预先淡出或画面重置。

`signet.js` 根据实心区域计算连续传播时间场，并从同一份实心覆盖率向内取 2px 边缘生成未点亮轮廓，避免独立线稿与动画错位。用同一个 Canvas 逐像素完成轮廓、流动光前锋和浅粉白实心终态。旧版骨架短线段及最终淡入层已移除。原理及参数见 [刻印点亮算法](../../doc/刻印点亮算法.md)。
