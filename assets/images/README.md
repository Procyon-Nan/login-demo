# 刻印素材

`elysia-signet.png` 原样复制自用户提供的 `素材/刻印透明线稿.png`，用于登录前的紫色线稿。

`elysia-signet-solid.png` 原样复制自用户提供的 `素材/刻印.png`，用于最终浅粉白实心形状及素材自带泛光。完整保留原图的逐像素 RGB 和透明度，洋红色半透明像素属于泛光而非背景。泛光恢复原生完整强度，不叠加额外 CSS 光效；其显现由附近笔画亮度的连续扩散驱动。PNG 文件本身不作修改；画布外扩以容纳整张原图，主体与线稿对齐。

`signet.js` 根据实心区域计算连续传播时间场，用同一个 Canvas 逐像素完成线稿、流动光前锋和浅粉白实心终态。旧版骨架短线段及最终淡入层已移除。原理及参数见 [刻印点亮算法](../../doc/刻印点亮算法.md)。
