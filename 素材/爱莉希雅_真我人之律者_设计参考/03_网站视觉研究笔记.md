# 网站视觉研究笔记

日期：2026-09-21。以下“观察”来自本地已查看的官方图片，“建议”是针对当前网站的设计推导，不是官方设计规范，也不是已获确认的改版要求。

## 1. 形象识别应先于粉色装饰

观察：专题角色图呈现浅粉长发、尖耳、白色头饰、粉紫眼睛、白色服装、淡紫晶体与金色饰边。粉色与白色承担主体，晶体边缘及局部光效带出紫色。角色手旁的晶花与漂浮碎片提供了比“粉色渐变”更具体的识别线索。

依据：`01_角色与场景/01_真我人之律者_官方专题角色主视觉.png` 与 `02_真我人之律者_官方展示底图.png`。

建议：登录页可以只保留晶花、切面和少量角色线条，不必同时展示整张人物海报。原有“单个 token 输入框”的简洁要求仍然成立。

## 2. 浅色角色与暗色空间可以同时成立

观察：官方专题背景以暗紫为外围、粉紫柔光为中心，并有细密点阵及层叠的不规则边缘；角色本身仍然是明亮的粉白色。这提供了一个暗色页面不依赖纯黑的直接参考。

依据：`01_角色与场景/05_光辉矢愿_官方专题背景.png`。

建议：借鉴“暗紫空间 + 局部粉白焦点”的关系，而不是把点阵、边缘碎片和光晕全部复制进登录页。输入区附近保持低纹理密度，避免遮蔽细线和文字。

既有纪要中的 HEX 仍为候选值。本轮没有做自动取色或对比度验证，不能将这些候选色描述为官方精确色值。

## 3. 星海、晶体与童话需要区分用途

观察：“无瑕之人（下）”包含深蓝星空、粉紫晶体碎片、白色建筑和金色细部；“上”呈现水下生物、气泡与蓝紫流动曲线；“中”以森林、动物、花草和童话服饰为主。

依据：`02_武器与圣痕/03_爱莉希雅无瑕之人_上.png`、`04_爱莉希雅无瑕之人_中.png`、`05_爱莉希雅无瑕之人_下.png`。

建议：当前登录页优先采用“下”的晶体与星空关系；“上”适合研究轻盈漂浮感；“中”仅作柔和情绪参考。不要将所有场景颜色并入同一套主题，也不要用圣痕童话服装替换默认形象。

## 4. 对现有展开动画的转译

用户已明确的交互不变：一个中心点分别向左上与右下展开，构成单一输入框，不用厚重卡片。

候选表现：

1. 起始点可以是极小的菱形晶核，保持单一视觉焦点。
2. 两个对角沿原有轨迹展开，线条颜色由粉白过渡到淡紫，边缘只保留窄幅高光。
3. 展开结束后输入字符出现，装饰减弱，让焦点回到输入内容。
4. 提交时可让边缘光点短暂向中心汇聚，再进入业务页面。

这些是网页动画建议，并非已经在官方视频中核实的同款动作；本轮不指定时长和粒子数量，不修改当前动画。

## 6. 待后续决定

- 默认明亮还是暗色，是否同时实现双主题。
- 人物是否直接出现在登录页，还是只保留刻印与晶体意象。
- 背景保持静止，还是加入缓慢漂浮的细小元素。
- 输入框展开是否加入局部折射，还是仅保留颜色与线条变化。

本轮只收集参考并提出候选映射，以上没有自动变成开发任务。
