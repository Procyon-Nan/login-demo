# Elysia API 扩展字体样例

整理日期：2026-09-21。共 32 款候选，保留原 01–06 号，新增 07–32 号。本轮仅制作选型材料，登录页面及其当前字体未替换。

## 如何比较

1. 打开 [扩展字体对比.html](扩展字体对比.html)，可以筛选来源、风格和名称，并调整字号。
2. 勾选感兴趣的字体，再点击“只看已选”集中比较；所选结果只在本次打开期间保留，不写入浏览器存储。
3. 先比较字形，再看每款的暗色效果和 32px 小尺寸效果。主样例默认 44px，各字体保持自己的字宽，不拉伸补齐。
4. 确定喜欢的编号后，再针对它制作书写动画；本轮不以不同动画干扰字体判断。

## 比较时注意

- 风格分组为本项目的视觉判断，不是作者官方分类。
- 09、10、27 等候选带有小型大写或装饰性大写表现，页面实际字符串仍为 `Elysia API`。
- 18、25 的书法装饰较强，28 的字形实验性较强；保留它们是为了展示风格范围，不代表优先推荐。
- 全部 32 款均已在本地浏览器确认字体加载成功后截图，没有用系统替代字体冒充候选。
- 保留各字体源文件及原始授权；页面预览完全使用本地文件，不依赖在线字体服务。
