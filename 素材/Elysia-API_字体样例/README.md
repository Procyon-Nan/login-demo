## 候选说明

| 编号 | 字体 | 视觉判断与取舍 |
| --- | --- | --- |
| 01 | Cormorant Garamond Italic，500 字重 | 斜体衬线，字母独立可辨；优雅、柔和，适合兼顾可读性与艺术感。优先建议。 |
| 02 | Marcellus，400 字重 | 清楚稳重的古典字形；装饰较少，阅读最直接。 |
| 03 | Cinzel，400 字重 | 碑铭式字形，偏神话、史诗气质；小写以小型大写形式呈现，文本内容仍是 Elysia API。 |
| 04 | Italiana，400 字重 | 纤细而留白充足；轻盈，但很小尺寸下细笔画较弱。 |
| 05 | Allura，400 字重 | 保留流畅连笔，装饰较多；适合仍希望有签名感的方向。 |
| 06 | Tangerine Bold，700 字重 | 轻巧的书法字形，花体大写比较明显；可读性与装饰感之间偏向装饰。 |

以上为本次实际渲染后的设计判断，并非字体作者的评级。

对比统一使用 `Elysia API`、相同明暗配色、48px 主样例与 32px 底部尺寸样例，保持各字体本身字宽，没有人为拉伸或转为图片模拟字体。本轮没有制作动画，以便先确定字形。字体确定后再调整书写节奏及两侧横线。

全部字体来自 [Google Fonts 官方仓库](https://github.com/google/fonts)，每款字体来源页面见 `字体来源.json`；授权全文保存在对应字体目录。
