# 爱莉希雅主题网站视觉设计讨论纪要

> 整理日期：2026-09-21  
> 当前阶段：角色视觉定位与第一版候选调色板  
> 主要参考形态：《崩坏3》「真我·人之律者」

## 1. 项目目标

设计一个以《崩坏3》角色爱莉希雅为主题的网站。当前工作聚焦于根据角色人设与「真我·人之律者」的官方视觉，建立网站的颜色体系，并为后续界面设计提供可执行的 CSS 基础。

## 2. 角色与视觉定位

爱莉希雅是前文明「逐火十三英桀」第二位，刻印为「真我」，也是第十三律者。当前网站优先参考「真我·人之律者」形态，不将「粉色妖精小姐♪」时期较重的深粉、黑色和酒红作为主要视觉来源。

从官方角色视觉与相关内容中归纳出的核心意象包括：

- 星月、星海与始源
- 童话、无瑕、飞花与水晶
- 人性、爱与善
- 精灵、弓与权杖
- 柔和粉白、晶体紫、冰蓝光效和少量香槟金

「真我·人之律者」虽为冰冻元素角色，但角色辨识中心仍是粉色、洁白和淡紫。冰属性主要通过水晶、半透明光效与星海意象表现。网站若大面积使用传统冷蓝冰系配色，会削弱爱莉希雅本人的视觉辨识度。

## 3. 已明确的主题方向

网站采用两套同源主题，并与角色的两种形态建立对应关系：

| 网站主题 | 对应形态 | 色彩倾向 | 视觉气质 |
|---|---|---|---|
| 明亮模式 | 人之律者 | 粉白、浅粉、薰衣草紫、少量冰蓝 | 明亮、柔和、轻盈、无瑕、人性 |
| 暗色模式 | 始源之律者 | 深紫、夜空蓝紫、晶体紫、星海蓝、粉色高光 | 深邃、梦幻、星海、始源 |

两套主题保持同一个粉色 Primary，以保证切换主题后仍有连续的角色识别。背景、Surface、Secondary 与光效随形态变化。

暗色模式不采用简单的“黑底 + 粉字”。背景应偏深紫与夜空蓝紫，构成「往世星海」的空间感。

## 4. 第一版候选基础调色板

以下 HEX 是依据官方视觉做过网页适配的候选值，并非机械提取自某一张宣传图。

| 定位 | 色值 | 建议用途 |
|---|---|---|
| 无瑕白 Pristine White | `#FCF9FD` | 明亮模式主背景 |
| 花瓣白粉 Petal Mist | `#F7EAF3` | 卡片与 Section 背景 |
| 爱莉浅粉 Elysia Blush | `#F1B8D8` | 大面积柔和装饰 |
| 真我粉 Ego Pink | `#E58ABD` | 核心品牌色、图标、选中态 |
| 晶花粉 Crystal Bloom | `#F7A8D8` | 花瓣、粒子与发光效果 |
| 始源薰衣草 Origin Lavender | `#B8A2E8` | 第二主题色 |
| 真我紫 Ego Violet | `#7550A8` | 按钮、链接与重要交互 |
| 星海冰蓝 Elysian Ice | `#B9E8F5` | 水晶、高光与星海特效 |
| 无瑕金 Pristine Gold | `#C7A376` | 饰边、徽章与细线 |
| 深紫墨 Ego Ink | `#3A2946` | 正文、标题与深色元素 |

构成网站主要身份的五个核心候选色为：

```text
#FCF9FD → #F1B8D8 → #E58ABD → #B8A2E8 → #7550A8
```

冰蓝与金色均应控制用量。金色适合 1px 描边、小型图标、标题装饰及悬停高光，不适合作为大面积背景。

## 5. 当前 CSS 颜色草案

### 5.1 基础颜色变量

```css
:root {
  --ely-bg:             #FCF9FD;
  --ely-surface:        #F7EAF3;

  --ely-pink-soft:      #F1B8D8;
  --ely-pink:           #E58ABD;
  --ely-pink-glow:      #F7A8D8;

  --ely-lavender:       #B8A2E8;
  --ely-violet:         #7550A8;

  --ely-ice:            #B9E8F5;
  --ely-gold:           #C7A376;

  --ely-text:           #3A2946;
}
```

### 5.2 明亮模式主视觉渐变

渐变从温暖的粉白逐渐过渡到「始源 / 往世星海」意象的紫蓝区域：

```css
background:
  linear-gradient(
    135deg,
    #FCF9FD 0%,
    #F7EAF3 28%,
    #EADDF7 65%,
    #DDF2F8 100%
  );
```

### 5.3 暗色模式初步草案

```css
[data-theme="dark"] {
  --bg:        #171222;
  --surface:   #241A32;
  --primary:   #E58ABD;
  --secondary: #A88AE0;
  --accent:    #8FD9ED;
  --text:      #F8EEF7;
  --muted:     #B9AFC2;
  --gold:      #C7A376;
}
```

这套暗色值目前只是方向草案，尚未完成背景层级、边框、交互状态与对比度验证。

## 6. 当前结论的状态

### 已明确

- 主要视觉参考采用「真我·人之律者」。
- 明亮模式对应「人之律者」，暗色模式对应「始源之律者」。
- 两套模式共享爱莉希雅标志性的粉色 Primary。
- 冰蓝与香槟金作为克制使用的辅助色。
- 暗色模式以深紫、晶紫和星海蓝构成，不以纯黑作为视觉核心。

### 候选方案，尚未最终确认

- 表格中的全部 HEX 色值。
- 两套模式的完整语义色映射。
- 主视觉渐变的角度与色标位置。
- 发光强度、透明度、阴影和材质规则。

## 7. 建议的下一步

下一阶段先将现有颜色收敛为两套完整的语义 Design Tokens，至少覆盖：

```text
background / surface / surface-elevated
text / text-muted
primary / primary-hover / primary-active
secondary / accent
border / divider / focus-ring
glow / shadow / gradient
success / warning / error / info
```

随后进行 WCAG 文本与交互对比度检查，再进入组件、版式与动态效果设计。这样可以避免在页面制作过程中继续随意增加近似粉色或紫色。
